# Парсер предиктов

Собирает рынки предсказаний (prediction markets) с разных площадок в один формат и умеет:

- **list** — показать активные рынки: вопрос, вероятность YES, bid/ask, объём, ликвидность, дата закрытия;
- **arb** — найти одно и то же событие на разных площадках и посчитать разницу цен и арбитраж с учётом комиссий;
- **watch** — следить и присылать алерты в консоль или Telegram: новые рынки, резкое движение вероятности, арбитраж.

Нужен только Python 3.9+, сторонних библиотек нет.

## Площадки

| Площадка | Статус | Откуда данные |
|---|---|---|
| Polymarket | ✅ готово | публичный Gamma API, без ключа |
| Kalshi | ✅ готово | публичный Trade API v2, без ключа |
| LBank (LBank Predict) | ⏳ нужен доступ к сайту | публичного API нет, только внутренние эндпоинты сайта |
| MEXC (Prediction Markets) | ⏳ нужен доступ к сайту | публичного API нет, только внутренние эндпоинты сайта |

Как будут подключаться LBank и MEXC и как найти их эндпоинты — в [docs/lbank-mexc.md](docs/lbank-mexc.md)
(там же разведчик `tools/discover.py`).

Polymarket и Kalshi покрывают ещё и биржи, которые показывают их рынки у себя: Bitget Wallet, Phemex и KuCoin Predictions
работают на рынках Polymarket, а Coinbase и Robinhood — на рынках Kalshi. Цены там те же самые.

## Запуск

```bash
cd predicts-parser

python -m predicts sources                       # какие площадки есть
python -m predicts list                          # топ-50 рынков по объёму за сутки
python -m predicts list -q "bitcoin" --sort end  # по слову, ближайшие к закрытию сверху
python -m predicts list -s kalshi --category crypto -n 0 -f csv -o kalshi.csv
python -m predicts arb                           # совпадающие события, лучший доход сверху
python -m predicts arb --min-edge 0.01           # только связки с доходом от 1%
python -m predicts arb --min-spread 0.05 -f json -o spreads.json
```

Полный список параметров — `python -m predicts <команда> --help`.

### Арбитраж

Для каждой найденной пары считаются две связки: «YES на A + NO на B» и «NO на A + YES на B» по лучшим ask.
**Доход%** — прибыль на $1 выплаты, если купить обе стороны: `1 − (цена A + цена B + комиссии)`.

- Комиссия Kalshi считается по их формуле `0.07 × P × (1 − P)`. Для остальных по умолчанию 0,
  свою можно задать так: `--fee lbank=0.0006` (доля от цены контракта).
- Пары находятся по тексту вопроса: страйки и числа обязаны совпасть, даты закрытия — отличаться не больше чем на `--max-days`.
  Это **кандидаты**. Условия разрешения (источник цены, время фиксации) на площадках бывают разными — перед сделкой их надо сверить.
- Проверенные вручную пары можно закрепить в `pairs.json` (пример — `pairs.example.json`) и передать через `--pairs pairs.json`.
- `⇄` в таблице значит, что YES одной площадки соответствует NO другой (например, «Лейкерс — Селтикс» против «Победят Селтикс?»).

### Алерты

```bash
export TELEGRAM_BOT_TOKEN=123456:ABC...   # токен от @BotFather
export TELEGRAM_CHAT_ID=123456789         # твой chat_id (например, через @userinfobot)

python -m predicts watch                                  # опрос раз в 2 минуты
python -m predicts watch --keywords btc,eth,fed --move 0.03 --window 30
python -m predicts watch --no-new --min-edge 0.02 --min-volume 5000
python -m predicts watch --once                           # один проход — для cron
```

- **Новый рынок** — появился рынок, которого не было в прошлых проходах. Первый запуск только запоминает текущие рынки.
- **Движение** — вероятность изменилась на `--move` (по умолчанию 5 п.п.) за `--window` минут (по умолчанию 60).
- **Арбитраж** — доход связки не меньше `--min-edge` (по умолчанию 1%).
- Один и тот же алерт повторяется не чаще, чем раз в `--cooldown` секунд (по умолчанию час).

История цен хранится в `predicts.db` (SQLite) в текущей папке (другой файл — `--db`), записи старше 7 дней удаляются.
Без токена Telegram алерты печатаются только в консоль.

## Как добавить площадку

Создать `predicts/sources/<имя>.py` с классом-наследником `Source`. Его метод `fetch()` возвращает список `Market`
(см. `predicts/models.py`; цены в долях 0..1). Потом добавить класс в `SOURCES` в `predicts/sources/__init__.py`.
Образцы — `polymarket.py` и `kalshi.py`.
